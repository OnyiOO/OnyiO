Project Highlights

Fall 2024

Pulse Width Modulation Circuit: Using an MSP-EXP430FR2433 and Code Composer Studio, I created a color modulation circuit. I selected colors which could be created through percentage mixtures of red, green, and blue LEDs. For example, turquoise, shown above, can be represented when red is 40% on, green is 80% on, and blue is 80% on. The switches on the MSP430 are connected to each LED and are ticked in increments of 10% until the color is achieved. The duty cycle shown in the second image controlled the intensity of the color shown on the LED, where 10% is a dim white light and 90% is a very intense color.
